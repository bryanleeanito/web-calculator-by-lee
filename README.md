# Calculator Web by Lee

A simple web-based calculator featuring dark/light mode and keyboard support.

---

## Disclaimer

This project is currently in the development stage (beta). It was created for learning purposes and personal use. It has not yet been optimized for production or for all devices.

---

## Features

- Basic operations: +, -, ×, ÷
- Dark/Light mode toggle
- Keyboard support
- Responsive design
- Calculation history

---

| CSS | Styling & animation |
